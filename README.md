# Distance Calculation

## This program calculates the distance between two points using the math library to easily get the desired output.


## Steps on running the calculation program
1. Open the program
2. Run the program
3. Enter the needed values for x1, y1, x2, y2
4. The program will display the distance between the two points, rounded to two decimal places.

## Input Needed
- x1 - x-coordinate of the first point
- y1 - y-coordinate of the first point
- x2 - x-coordinate of the second point
- y2 - y-coordinate of the second point

## Sample Output
- Enter x1: 2
- Enter y1: 3
- Enter x2: 7
- Enter y2: 8
- 
"The distance between the two points is: 7.07"
